Cara Kerja: Sistem membaca teks dari setiap halaman PDF menggunakan engine lokal berkecepatan tinggi. Identitas dokumen dideteksi secara otomatis berdasarkan profil pilihan Anda: Siswa (NISN & Nama), Guru/Pegawai (NIP/NUPTK & Nama), Surat Dinas / SK (Nomor & Perihal), atau Label Kustom Bebas.

Metode Pemisahan:
• Auto-detect (Rekomendasi): Otomatis mendeteksi pergantian entitas saat ID / Nama baru muncul di halaman berikutnya (panjang halaman per entitas bisa bervariasi).
• Halaman Tetap: Memotong setiap N halaman per file (contoh: 1 halaman untuk Kartu Ujian/Slip Gaji, 2 halaman untuk SKL/Sertifikat).
• Kata Kunci Halaman Pertama: Memotong setiap kali judul/kata kunci tertentu ditemukan di awal dokumen baru.

Hanya berfungsi pada file PDF berbasis teks digital. Jika dokumen adalah hasil scan gambar murni tanpa teks, gunakan mode Jumlah Halaman Tetap atau jalankan OCR PDF terlebih dahulu.
